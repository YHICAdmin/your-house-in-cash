# XML Sitemap

## Purpose

Provide search engines with a current, machine-readable inventory of the website's public canonical URLs.

## Route and Canonical Domain

- Sitemap route: `/sitemap.xml`.
- Canonical domain: `https://www.yourhouseincash.com`.
- The sitemap is generated by the Next.js metadata-route implementation at `src/app/sitemap.ts`.

## Included URLs

The sitemap includes absolute URLs for the following public routes:

- Homepage: `/`.
- Static site pages: `/about-us`, `/areas-we-buy-in`, `/blog`, `/buyers`, `/contact`, `/get-cash-offer`, `/privacy-policy`, `/sell-property-portfolio`, and `/terms-of-service`.
- Area pages generated from `src/data/areas.ts` using each area's `getAreaPagePath` destination, except Cleveland because its canonical page is the Homepage (`/`), which is already included.
- Situation pages generated from `src/data/situations.ts`.
- Blog article pages generated from `blogSlugs` in `src/lib/blog-content.ts`.
- Blog topic pages generated from `readBlogTopics` in `src/lib/blog-content.ts`.
- Valid blog topic pagination pages generated from each topic's article count, with six articles per page.

## Metadata

- Each blog article URL includes its documented publication date as `lastModified`.
- URLs without an authoritative modification date do not include `lastModified`.

## Exclusions

- API routes, form-submission routes, and other non-public routes are excluded.
- URLs that are not generated by the site's documented static, area, situation, or blog route sources are excluded.

# Page Routing

* Canonical route: `/terms-of-service`.
* The route is the destination used by the Site Footer and the Minimal Footer.

# Header and Footer

* Use the existing shared Site Header and Site Footer.

# Terms of Service

## Purpose

Provide a plain-English summary of permitted website use, the informational nature of site content, the non-binding nature of a request for an offer, and the governing terms for the website.

## Layout

* Use the global `Background` (`#FFFFFF`) and the global Content Container.
* Present the complete terms as one readable, left-aligned text column. On Desktop, the column occupies Grid Columns `1–8`; on Tablet and Mobile, it occupies all available columns.
* Preserve the global Line System behind the foreground content.
* Use the global Section spacing.
* Do not add promotional content, calls to action, imagery, animation, or decorative graphics.

## Page Heading

### Content

* H1: `Terms of Service`.
* Effective date: `October 13, 2026`.

### Component and Semantics

* Use an `h1` followed by the effective-date paragraph.

### Visual Design and Spacing

* The H1 uses global Display typography.
* The effective date uses global Body Small typography and Text Secondary color.
* Use `S` (`16px`) between the H1 and effective date.
* Use `XL` (`48px`) between the complete Page Heading and the terms content.

## Terms Content

### Content

* Headings after the H1 use `h2` semantics in the documented order.
* Use the documented Text Link Component for all links, including the Privacy Policy, email address, and telephone number.
* The public-facing text is implemented in the route component and must remain aligned with the approved legal draft.

### Visual Design and Spacing

* Section headings use global H3 typography.
* Body copy uses global Body typography.
* Use `L` (`32px`) between adjacent terms sections and `S` (`16px`) between a section heading and its first paragraph.
